# gol-sweeper

The idea for this project is to create a version of Minesweeper whose mine locations "evolve" using a cellular automaton-type model, such as [Conway's Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life). As the rules of the original Minesweeper game are influenced by observing the states of neighboring cells in a grid, we were curious about how varying the rules for this model may affect gameplay.

This project is ongoing and will likely contain many bugs. [This tutorial](https://www.youtube.com/watch?v=LEiL4rrZbqQ) was referenced for handling events in the base game and getting accustomed to the Godot game engine.
