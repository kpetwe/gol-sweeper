# Game of Life Minesweeper

The idea for this project is to create a version of Minesweeper whose mine locations "evolve" using a cellular automaton-type model, such as [Conway's Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life). As the original Minesweeper game requires observing the states of neighboring cells in the grid, we were curious about how adding cell generation affects gameplay.

This project is ongoing and will likely contain many bugs. 

I am new to Godot. I referenced [this tutorial](https://www.youtube.com/watch?v=LEiL4rrZbqQ) in part for importing assets and handling mouse events for minesweeper, so structural similarities between it and the code for the base game may be present.
